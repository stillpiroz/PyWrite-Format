# AI Usage Policy

AI is a tool to assist contributors, not a replacement for their skills or responsibility.

## 1. Translation

Using AI for translation is permitted, including commit messages, comments, and docstrings.

We prefer that you write these yourself. If your English is not strong enough:

- Write the original text or explain your intended meaning.
- Ask AI to translate it, not create new content.
- Review the translation to ensure it is accurate.

## 2. Understanding the Project

Before using AI, read the project's `README.md`, `CONTRIBUTING.md`, and source code.

You may use AI to help understand code and explain how different parts of the project work.

## 3. Writing Code

- Do not copy and paste AI-generated code.
- Write your own code and understand how it works.
- Follow project standards and guidelines.
- Keep your code readable and maintainable for other contributors.

## 4. Documentation

We prefer that you write documentation yourself.

You may use AI to translate or polish your own writing, but not to create entire documents on your behalf.

## 5. Finding Bugs

You may use AI to help identify bugs and review code.

However, understanding the problem, investigating its cause, and implementing the solution are your responsibility.

## 6. Responsibility

Always review and verify AI-assisted results. You are responsible for everything you contribute to the project.

---

**Remember: AI is a tool, not a replacement for you.**
